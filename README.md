# rippl Extension

Browser extension that tracks AI tool usage and shows how AI shapes your day. All data stays local.

## Development

```bash
npm install
npm run dev          # Dev mode with hot reload
npm run build        # Production build
npm test             # Run tests
```

## Load in Chrome

1. Run `npm run build`
2. Open `chrome://extensions`
3. Enable "Developer mode"
4. Click "Load unpacked" → select `.output/chrome-mv3/`
